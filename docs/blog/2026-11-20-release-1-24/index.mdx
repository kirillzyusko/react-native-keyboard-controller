Version `1.24.0` is a small release ahead of React Native 0.89. It adds Swift
Package Manager (SwiftPM) support on iOS and on-demand view managers on Android.

<!-- truncate -->

## Swift Package Manager on iOS

The npm package now includes a `Package.swift` manifest so React Native can
autolink the library in apps that use SwiftPM. This prepares the library for
React Native 0.89, where the team plans to make SwiftPM the default for iOS
builds. [React Native's SwiftPM rollout plan](https://reactnative.dev/blog/2026/10/19/react-native-0.88#experimental-swift-package-manager-support).

You can already use `1.24.0` with the opt-in SwiftPM setup in React Native 0.88.
If your app uses SwiftPM, update the package and rebuild your iOS app.
[Implementation and testing in #1696](https://github.com/kirillzyusko/react-native-keyboard-controller/pull/1696).

## On-demand view managers on Android

`KeyboardControllerPackage` now implements `ViewManagerOnDemandReactPackage`.
With React Native 0.89, the framework can defer creating each view manager and
building its view configuration until JavaScript first uses the corresponding
native view. This can make cold starts a little faster in apps that first use
these views after the initial render.
[Implementation and cold-start profiles in #1767](https://github.com/kirillzyusko/react-native-keyboard-controller/pull/1767).
