Version 1.24 — Swift Package Manager and on-demand Android view managers 📦

November 20, 2026 · 3 min read
Kirill Zyusko
Library author

Version 1.24.0 is an intentionally small release ahead of React Native 0.89. It adds Swift Package Manager (SwiftPM) support on iOS and on-demand view managers on Android.

📦 Swift Package Manager on iOS​

The npm package now includes a Package.swift manifest so React Native can autolink the library in apps that use SwiftPM. CocoaPods remains supported, and 1.24.0 continues to work with earlier supported versions of React Native.

You can already use 1.24.0 with the opt-in SwiftPM setup in React Native 0.88.

🤖 On-demand view managers on Android​

If a native view only appears on a later screen, its configuration can wait until you get there. KeyboardControllerPackage now implements ViewManagerOnDemandReactPackage so React Native can do that setup on demand for the library's views.

What I measured

Median JS-thread CPU time in UIManager.getConstants went from 29.9 ms to 27.0 ms, a saving of about 3 ms.

Three milliseconds is a small win for one package. If several native modules in your app can defer work this way, those savings can add up to a much faster startup.

🤔 What's next?​

I'm also working on the interactive back swipe on iOS. When you are writing a reply, you might swipe back. The composer should stay in sync with the keyboard the whole time so you can pick up right where you left off.

Before the fix, the composer drops behind the keyboard.After the fix, the composer stays above the keyboard.

I really hope to ship this in 1.25.0 before the new year.

I've moved all the example apps to React Navigation's native stack. I can now test keyboard behavior during native screen transitions in the examples, which should make future releases more reliable for apps using the same navigator.

I'm also working on getting the end-to-end tests running on Android 17. Covering a wider range of Android versions should help me catch version-specific bugs before they make it into a release.

As always, my top priority is resolving open issues, so expect more bug fixes as I work to make the library more stable:

  • Issues with more 👍 reactions are prioritized first. That's how I track what matters most to the community.
  • Issues labeled "sponsor 💖" receive highest priority as part of dedicated sponsor support.

Stay tuned and follow me on X and GitHub for updates. Thank you for your support! 😊
